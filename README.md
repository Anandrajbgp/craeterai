# CreatorAI - AI-Powered Video & Content Creation Suite (Flutter)

A complete, production-ready multi-platform application (Android, iOS, Web, Desktop) built with **Flutter**, guiding users through a strict 5-step linear wizard pipeline from ideation to final platform export and publishing.

## 🚀 Pipeline Steps

1. **Idea & Script Generation**: Topic prompt, platform selector, tone/duration dropdowns, AI regeneration, and fully editable scene cards (voiceover text, visual cues, reorder, add, delete).
2. **Voicover & Audio Studio**: Live audio waveform preview player, AI neural voice selection grid, background music mixer, and scene mic recording override.
3. **Visual Storyboard & Timeline**: Synced video/image preview, horizontal timeline track, visual asset customizer, and AI text-to-image prompt generator.
4. **Auto-Captions & Effects**: Video player with dynamic kinetic captions, Alex Hormozi style preset toolbox, font size/color controls, and auto-transcription.
5. **AI SEO, Thumbnails & Export**: Final video master render progress bar, AI SEO metadata editor (titles, description, tags), and direct publish/export simulation.

## 🛠️ Tech Stack
- **Framework**: Flutter (Dart)
- **State Management**: Provider
- **UI Design**: Material 3 Dark Creator Theme (Slate-950 + Violet/Purple AI Accents)
- **Icons**: Lucide Icons / Material Icons

## 📱 How to Run
```bash
flutter pub get
flutter run
```
